---
title: "Get Origination"
api: "GET /v1/originations/{id}"
description: "The current safe representation of an origination."
---

Returns the state, stage, action, timestamps, deadline, and, when the person has something to do, the `user_url`. Poll it every 5 to 15 seconds during the first minute, then back off to 60 seconds. Terminal states never change.

## Path

<ParamField path="id" type="string" required>
  The `migration_id` returned on submission.
</ParamField>

## Response

The same representation as [Create Origination](/api-reference/partner/originations/create-origination). A `404` means the id is unknown to your credential, whether because it does not exist or because it belongs to another partner.
