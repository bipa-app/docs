---
title: "Create Origination"
api: "POST /v1/originations"
description: "Submit one person to Bipa. Accepted asynchronously; poll for the outcome."
---

Submits an immutable envelope for one person. Bipa answers `201` with the current representation on first acceptance and `200` with the existing origination on an identical retry. See [Originations](/originations) for the envelope rules, the lifecycle, and the error codes.

## Request

<ParamField body="external_id" type="string" required>
  Your identifier for this attempt, 1 to 64 characters. Reuse it only for byte-equivalent retries.
</ParamField>
<ParamField body="tax_id" type="object" required>
  `{ "type": "cpf", "value": "64780788099" }`. Eleven digits, no mask.
</ParamField>
<ParamField body="email" type="string" required>
  Valid email, normalized to lowercase.
</ParamField>
<ParamField body="phone" type="string" required>
  Valid E.164 phone.
</ParamField>
<ParamField body="consents" type="object" required>
  `data_sharing` and `bipa_terms`, each with `accepted_at`, `ip`, `user_agent`, `document_version`, `document_digest_sha256`, and `locale`.
</ParamField>
<ParamField body="kyc" type="object" required>
  `level` is `basic` or `full`. For `full`, also `selfie_file_url` and `document_files` (at most one `front` and one `back`, each with `side` and `file_url`).
</ParamField>
<ParamField body="balances" type="array" required>
  The complete portfolio of non-zero positions, or an empty list. Each item: `asset`, `network`, `contract` (or `null`), `decimal_scale`, and `quantity` as a string of digits in the smallest unit.
</ParamField>
<ParamField body="address" type="object">
  Optional. `zip_code`, `street`, `number`, `complement` (optional), `district`, `city`, `state`, `country`.
</ParamField>
<ParamField body="bureau_blobs" type="array">
  Optional. One item per `dataset` with the provider's raw `payload`, up to 256 KiB each.
</ParamField>

## Response

<ResponseField name="origination_id" type="string">
  The id you poll. A UUIDv7.
</ResponseField>
<ResponseField name="state" type="string">
  `pending`, `approved`, `denied`, `expired`, or `settled`.
</ResponseField>
<ResponseField name="stage" type="string">
  Where the origination is within its state.
</ResponseField>
<ResponseField name="action_required" type="string">
  The next step to render. `none` when there is nothing to do.
</ResponseField>
<ResponseField name="created_at" type="string">
  RFC 3339.
</ResponseField>
<ResponseField name="updated_at" type="string">
  RFC 3339. Unchanged means nothing changed.
</ResponseField>
<ResponseField name="deadline_at" type="string">
  RFC 3339. Null once terminal.
</ResponseField>
<ResponseField name="user_url" type="string">
  Present only when the person has a valid action. Locates, does not authenticate.
</ResponseField>
