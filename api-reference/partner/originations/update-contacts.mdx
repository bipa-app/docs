---
title: "Update Contacts"
api: "PATCH /v1/originations/{id}/contacts"
description: "Correct the imported email and/or phone while the origination is waiting for it."
---

Allowed only while the representation is `pending` / `contact_resolution_required` / `correct_contacts`. Anything else answers `409 contact_update_not_allowed` and writes nothing. An accepted correction returns the origination to `pending` / `validating` with a fresh deadline. A replay with the same normalized contacts is idempotent.

Only contacts can be corrected. Tax id, KYC evidence, consents, address, and balances are immutable; documents are recaptured by the person inside Bipa.

## Path

<ParamField path="id" type="string" required>
  The `origination_id`.
</ParamField>

## Request

<ParamField body="email" type="string">
  Valid email. At least one of `email` and `phone` is required.
</ParamField>
<ParamField body="phone" type="string">
  Valid E.164 phone.
</ParamField>

## Response

The safe representation. It never echoes the contacts.

<RequestExample>
```json Request
{
  "email": "new-email@example.com",
  "phone": "+5531988887777"
}
```
</RequestExample>
